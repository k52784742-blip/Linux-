# Linux 学习与开源项目测试环境

这是一个非营利性的个人学习仓库，主要用于记录 Linux 系统运维的学习过程，以及测试各类轻量级开源工具的部署。

## 📖 项目简介
本项目旨在通过实际操作 Linux 服务器，掌握基础运维命令、Docker 容器化部署以及 Nginx 反向代理配置。同时，这里也作为个人小型工具集网站的测试部署环境。

## 🎯 学习目标
- 掌握 Linux 基础操作与系统运维
- 学习 Docker 与 Docker Compose 的使用
- 实践 Nginx 配置与网站部署
- 测试各类轻量级开源 API 工具的运行情况

## 🛠️ 技术栈
- 操作系统：Debian 12 (稳定、轻量，适合低配服务器)
- 容器化：Docker
- 反向代理：Nginx
- 后端：Node.js / Python (用于测试开源 API 工具)
- 前端：简单的 HTML/JS 页面
